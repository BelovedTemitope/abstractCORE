# Contributing

abstractCORE is at an early stage, so the most useful contributions right now are:

- **Feedback on the model** – open an issue if the layering, decision ownership or node model doesn't fit how you build.
- **Try the prototypes** – open the HTML files in `prototype/` and report anything confusing or broken.
- **Design discussion** – proposals for the graph core and JSON schema in [docs/architecture.md](docs/architecture.md).

For code changes, open an issue first so we can agree on direction, then send a pull request against `main`. By contributing you agree your work is licensed under the [Apache License 2.0](LICENSE).
